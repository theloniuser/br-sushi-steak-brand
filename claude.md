# [Brand Name] Brand Guidelines

A brand guidelines website built with design-os.

## Quick Start

See `GETTING-STARTED.md` for setup instructions.

## Tech Stack
- React + TypeScript + Vite
- Tailwind CSS
- design-os framework

## Key Files
- `product/sections/brand-foundation/data.json` — colors, typography, logos, fonts
- `product/sections/visual-assets/data.json` — textures, icons, decorative elements
- `product/sections/menus/data.json` — menu documents
- `product/sections/signage/data.json` — signage assets
- `public/assets/` — all static brand assets

## Development
```bash
npm install
npm run dev
```
