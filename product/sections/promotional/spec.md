# Promotional Specification

## Overview
The Promotional section gives marketing teams and partners a central library of ready-to-use marketing materials for BR Sushi & Steak, organized by channel: social media graphics, print/digital advertising, and email/digital campaigns.

## User Flows
- Browse promotional assets grouped by channel (social, print/digital ads, email campaigns)
- Preview an asset in full size, with multi-page PDF support for print ads
- Download individual assets or all assets in a channel as a zip
- View asset dimensions and channel details

## UI Requirements
- Single scrolling page layout with a section per channel
- Each channel section has a heading, description, and "Download All" button
- Asset cards show a preview thumbnail, name, and description with hover actions to view or download
- Clicking a thumbnail opens a full-size lightbox (image viewer for images, in-page PDF viewer for multi-page PDFs)
- Responsive grid layout (2 columns tablet, 3 columns desktop)
