## Adding Your Files

1. **Gather your assets** - Collect all files (logos, fonts, menus, signage, etc.)
2. **Match the naming** - Ensure filenames match exactly as listed in data.json files
3. **Place in folders** - Copy files to the appropriate subdirectories
4. **Test downloads** - Run the dev server and test that download buttons work

## File Format Notes

- **SVG**: Vector format, best for scalability and web use
- **PNG**: High-resolution raster format (@3x for retina displays)
- **EPS**: Vector format for print production
- **AI**: Adobe Illustrator source files
- **PSD**: Adobe Photoshop source files
- **DWG**: AutoCAD drawing files for architectural plans
- **PDF**: Universal format for viewing and printing
- **OTF/TTF**: OpenType/TrueType font formats

## File Size Guidelines

- **Logos**: SVG (10-30 KB), PNG (60-200 KB), EPS (0.5-2 MB)
- **Fonts**: OTF/TTF (40-100 KB per file)
- **Photography**: JPG (500 KB - 3 MB high-res)
- **Layouts**: DWG (2-4 MB), PDF (4-7 MB)
- **Menu Boards**: PSD/AI (20-50 MB), PDF (5-20 MB), PNG (5-15 MB)
- **Signage**: DWG (1-4 MB), PDF (3-8 MB), AI (5-15 MB)
- **Promotional**: PDF (3-35 MB), AI (8-48 MB), PNG (8-18 MB)

## Next Steps

After adding your assets:
1. The screen designs will automatically reference these files
2. Download buttons will serve the actual files when clicked
3. Test in development: `npm run dev` → click download buttons
4. When you build for production (`npm run build`), these assets will be included in the `dist/` folder

## Development vs Production

**Development** (`npm run dev`):
- Files served from `public/assets/` → `http://localhost:3000/assets/`
- Hot module reloading enabled
- Fast file access

**Production** (`npm run build`):
- Files copied to `dist/assets/`
- Optimized for deployment
- Same URL structure: `/assets/...`

## Notes

- The `public/` directory is automatically served at the root URL by Vite
- Any file placed in `public/assets/` is accessible at `/assets/` in your app
- No code changes needed - data.json files already reference these paths
- Maintain this directory structure for consistency with section organization
